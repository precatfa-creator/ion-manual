مصطلحات هذا النظام تخصّ التطبيقات المخصّصة (ion، ion_crm_sales، aion_custom_hr، ion_career، ion_intercompany_transfer، biotime) تحديداً — وليست شرحاً لمصطلحات ERPNext/HRMS القياسية.

| المصطلح كما يظهر على الشاشة | ماذا يعني | الفصل |
| --- | --- | --- |
| **نوع المادة** (Material Type) | تصنيف الصنف (Hardware/Software/Stationery/...) لتصفية الأصناف في الطلب | [المشتريات](/buying/material-request/) |
| **Bussniess unit** (كذا، بالتهجئة الأصلية) | بُعد محاسبي شجري لوحدة العمل | [الأصناف والأبعاد](/buying/masters/) |
| **Revenue** | بُعد محاسبي شجري لنوع الإيراد | [الأصناف والأبعاد](/buying/masters/) |
| **Opportunity From / نوع الفرصة** | يحدّد أي مسار بيع من المسارات الخمسة يخصّ هذه الفرصة | [نظرة عامة على الفرص](/sales-crm/opportunities-overview/) |
| **BA** (في السياق المالي) | Business Accounts — قطاع حسابات الأعمال في احتساب العمولة | [العمولات](/sales-crm/commissions/) |
| **New Lead / Old Accounts / Upsell** | نوع صفقة العمولة: عميل جديد بالكامل / تجديد حساب قائم / بيع إضافي على عقد قائم | [العمولات](/sales-crm/commissions/) |
| **Above Target** | معدل عمولة أعلى يُطبَّق عند تجاوز الهدف المحدَّد | [العمولات](/sales-crm/commissions/) |
| **Accrual / ترحيل الاستحقاق** | تحويل العمولة المحتسَبة إلى قيد محاسبي فعلي (Journal Entry) | [العمولات](/sales-crm/commissions/) |
| **Late Hours / ساعات التأخير** | سجلّ تلقائي يجمع دقائق تأخير الموظف وجزاءها المحتسَب | [التأخير والخروج المبكر](/hr/attendance-lateness/) |
| **Assume as Absent** | حد أقصى لدقائق التأخير يتحوّل بعده اليوم إلى غياب كامل بدل تأخير | [إعدادات الموارد البشرية](/hr/settings/) |
| **penalty managment** (كذا) | المستند الذي ينقل جزاء التأخير/الخروج المبكر إلى راتب الموظف فعلياً | [إدارة الجزاءات](/hr/penalties/) |
| **Anchor Date** | تاريخ مرجعي (تعيين الموظف أو تاريخ مخصَّص) تُحسَب منه دورة التقييم السنوي | [التقييمات السنوية](/hr/appraisals/) |
| **Discovery / اكتشاف** | موظف ظهر على جهاز البصمة ولم يُطابَق بعد بسجل موظف في النظام | [مراجعة موظفي الجهاز الجدد](/biotime/employee-discovery/) |
| **Fetch / Sync (BioTime)** | سحب بصمات الحضور من جهاز BioTime إلى النظام | [إعداد تكامل البصمة](/biotime/biotime-setup/) |
| **RG / Scope / QA / Surveyor / TA** | تسميات قديمة/وصفية؛ أدوار الموافقة الحالية هي مدير الحساب وSales Engineer وSurveyor Manager | [الأدوار المسؤولة عن كل مسار](/sales-crm/opportunities-overview/) |
| **Custom User Permission** | روابط من آلية صلاحيات قديمة؛ دالة الإنشاء التلقائي الحالية متوقفة | [الصلاحيات والإشعارات](/buying/permissions/) |
